## 1. ข้อมูลภาพรวมโปรแกรม
โปรแกรมบันทึกรายรับ-รายจ่ายแบบ Command Line Interface (CLI) พัฒนาด้วยภาษา Python โดยใช้แนวคิดเชิงวัตถุ (OOP) จัดเก็บข้อมูลลงไฟล์ข้อความอัตโนมัติ (Data Persistence) เพื่อให้สามารถบันทึก ดูประวัติ และสรุปยอดคงเหลือได้อย่างเป็นระบบ

## 2. โครงสร้างและการทำงานทางเทคนิค (Technical Architecture)

### 2.1 การนำเข้าโมดูล (Module Imports)
* `import os`: ใช้ตรวจสอบการมีอยู่ของไฟล์ข้อมูล (`os.path.exists`) ก่อนทำการโหลดไฟล์ ป้องกันข้อผิดพลาด FileNotFoundError
* `from datetime import datetime`: ใช้ดึงวันที่ปัจจุบันผ่าน `datetime.now()` และจัดรูปแบบสตริง `YYYY-MM-DD` เป็นค่าเริ่มต้นกรณีที่ผู้ใช้ไม่ได้ระบุวันที่

### 2.2 การเขียนโปรแกรมเชิงวัตถุ (OOP Concept)
* **คลาส `Transaction` (Data Model Class):**
  * ทำหน้าที่จำลองข้อมูลธุรกรรม 1 รายการ
  * **Attributes:**
    * `self.type_str`: ชนิดของรายการ (`Income` หรือ `Expense`)
    * `self.category`: หมวดหมู่ของรายการ เช่น เงินเดือน, ค่าอาหาร
    * `self.amount`: จำนวนเงิน (แปลงเป็น `float`)
    * `self.date_time`: วันที่ทำรายการ
  * **Method `to_text(self)`:** ทำหน้าที่แปลง Attribute ใน Object ให้อยู่ในรูปข้อความคั่นด้วยเครื่องหมาย Pipe (`|`) เพื่อบันทึกลงไฟล์
* **คลาส `ExpenseTracker` (Controller/System Class):**
  * ทำหน้าที่เป็นตัวจัดการหลักของระบบ
  * **Attributes:**
    * `self.file_name`: ชื่อไฟล์ฐานข้อมูล (`expenseList.txt`)
    * `self.transactions`: ตัวแปรเก็บรายการทั้งหมด

### 2.3 การใช้งานโครงสร้างข้อมูลแบบ Array/List
* `self.transactions = []`: ลิสต์ (Array) ในคลาส `ExpenseTracker` ใช้สำหรับเก็บ Object ของ `Transaction` ในหน่วยความจำ (RAM) ระหว่างโปรแกรมทำงาน
* มีการดำเนินการพื้นฐานกับ List:
  * `.append()`: เพิ่ม Object ธุรกรรมใหม่เข้าไปในลิสต์
  * วนลูปด้วย `for idx, tx in enumerate(self.transactions, 1):` เพื่ออ่านข้อมูลออกมาแสดงผลและคำนวณยอดเงิน

### 2.4 ฟังก์ชันและเมธอด (Functions & Methods)
* `add_transaction(self, type_str, category, amount, date_time=None)`: ตรวจสอบความถูกต้องของข้อมูล (Validate ยอดเงินต้องมากกว่า 0), สร้าง Object `Transaction`, เพิ่มลงลิสต์ และบันทึกข้อมูล
* `show_report(self)`: วนลูปอ่านข้อมูลในลิสต์ เพื่อสรุปผลรวมรายรับ (`total_income`), รายจ่าย (`total_expense`) และคำนวณยอดคงเหลือสุทธิ (`balance`)
* `save_to_file(self)`: เปิดไฟล์ในโหมดเขียนทับ (`"w"`) และเขียนข้อมูลของ Object ทั้งหมดในลิสต์ลง Text File
* `load_from_file(self)`: อ่านข้อมูลบรรทัดต่อบรรทัดจากไฟล์ แยกสตริงด้วย `.split("|")` แล้วนำข้อมูลที่ได้มาประกอบเป็น Object `Transaction` ใหม่ใส่กลับเข้าไปในลิสต์

## 4. วิธีการใช้งานโปรแกรม (User Guide)
ความต้อวการของระบบ
* Python 3.10 ขึ้นไป (เนื่องจากมีการใข้คำสั่ง match-case)
* ขั้นตอนการรันโปรแกรม
 * 1. เปิด Terminal ในโฟลเดอร์ที่เก็บโค้ด
 * 2. รันคำสั่ง
   ```bash
      python main.py
 * 3. เลือกเมนูตามตัวเลข 1-4
   ** กด 1 (Add Income): บันทึกรายรับ (ระบุหมวดหมู่, ยอดเงิน, และวันที่ โดยสามารถกด Enter เพื่อใช้วันที่ปัจจุบันได้)
   ** กด 2 (Add Expense): บันทึกรายจ่าย (ระบุหมวดหมู่, ยอดเงิน, และวันที่ โดยสามารถกด Enter เพื่อใช้วันที่ปัจจุบันได้)
   ** กด 3 (View Report): แสดงรายการประวัติย้อนหลังทั้งหมด พร้อมรายงานสรุปรายรับรวม, รายจ่ายรวม และยอดคงเหลือสุทธิ
   ** กด 4 (Exit): บันทึกข้อมูลและออกจากโปรแกรม
